How it works

    
One C function per state. Each call reads one byte, writes the output for that transition, and returns the next state. main() is just while ((c = getchar()) != EOF) state = step(state, c, &pos);

    
    
      
  • A comment becomes one space; newlines inside block comments are kept, so error line numbers still match the source.
    • 
      
  • / is held for one byte: // and /* start comments; anything else (even a quote) writes the / and is processed as fresh input.
    • 
      
  • Line counting lives in step(), once for every state; the comment's start line is saved when /* is seen.
    • 
      
  • Tested with 251 golden cases, an independent table-driven oracle (random differential tests + libFuzzer), ASan/UBSan, Valgrind and ARM32 under QEMU.
    • 
    

  




Compiled from C with Emscripten; runs entirely in your browser. Source code is in a private repository.
